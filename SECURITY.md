# Security Policy

## Reporting a Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

We take security issues in DrogonClaw seriously — both bugs in our code and any way the tool itself could be turned against the people running it. If you've found something, please report it privately through one of these channels:

1. **Preferred — GitHub Security Advisory**. Open a private advisory using the "Security" tab on our GitHub repository. This is end-to-end private and keeps the disclosure tied to the commits / releases it affects.
2. **Email**. Send details to the maintainer's email with the subject line prefixed `[security] DrogonClaw:`. PGP isn't required; if you want to encrypt, ask in the first message and we'll exchange keys.
