## 🚀 HOW TO GET STARTED

### THREE SIMPLE STEPS

#### Step 1: Install (2-3 minutes)
```bash
npm install
```

This automatically:
- Creates directory structure
- Installs 18 npm packages
- Generates source files
- Sets up configuration

#### Step 2: Configure (1 minute)
```bash
cp .env.example .env
# Edit .env with your API key
# Example:
# AI_PROVIDER=claude
# ANTHROPIC_API_KEY=sk-ant-v4-xxx
```

#### Step 3: Run (1 minute)
```bash
npm run build   # Compile TypeScript
npm start       # Run CLI

# OR
npm run gateway  # Start server
```

**Total setup time: ~5 minutes**
