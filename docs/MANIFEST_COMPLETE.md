## 🎯 How Files Work Together

```
User runs: npm install
    ↓
[preinstall] create-dirs.js
    Creates directories: src/, tests/, docs/, etc.
    ↓
npm package download
    Installs: express, sqlite3, typescript, etc.
    ↓
[postinstall] full-setup.js
    Generates source files from embedded content
    Creates: src/types/index.ts, src/gateway/index.ts, etc.
    ↓
Ready for: npm run build
    TypeScript compiler
    Creates: dist/ folder with compiled JS
    ↓
Ready for: npm start or npm run gateway
    Runs the pentesting framework
```
